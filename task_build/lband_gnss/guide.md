# 使用说明与阅读导引

本文件将前述详细分析方案整理为可编辑的技术文档。研究对象为天基雷达发射对地面、船载及机载RNSS/GNSS用户接收机的非故意射频干扰，重点围绕1215–1300 MHz；相邻频段应按实际发射谱和受扰通道另行检查。本文是**分析实施方案，不是已完成的项目兼容性评估报告**，不包含任何真实项目的保密参数，也不宣称已经完成轨道仿真或接收机试验。

**核心认识：详细分析不一定更换“劣化比”这个判据，而是将初评的代表性参数、持续最坏照射和理想滤波等假设，替换为可追溯的实际参数、动态过程和经过验证的接收机响应。** RS.2165-0做出建议3、4规定了详评触发条件及参与要求，并仍引用相应允许劣化比。[R1]

本文的三类内容明确区分如下：

| 内容类型 | 标识与使用方式 |
|---|---|
| 文献原有方法与要求 | 用[R1]–[R7]标明来源及章节，不扩展其适用范围 |
| 工程实施补充 | 坐标实现、数据管理、事件区间算法、收敛检查、试验组织等，是本方案综合设计，不声称为ITU逐条强制规定 |
| 说明性假设算例 | 明确标为“演示假设”；不能代替真实设备或实测结果 |

正文按“范围与准则—参数—参考面—动态几何—波形耦合—接收机响应—多源聚合—验证—判定”展开。第14章延续0.387 dB的SAR5—SBAS初评案例，说明怎样正确推进详评；最后提供原文定位和交付物清单。另附的论文检索导读属于本次外部文献检索，与本方案的标准依据分开。

# 1　详细分析究竟比初步分析多做什么

## 1.1　初评回答“有没有潜在风险”

RS.2537-0附件2第3.1节的代表性算例先求最坏峰值干扰，再假定在一段名义时间内每个SAR脉冲都足以使接收机饱和，随后求有效脉冲占空比及劣化比。但报告同时说明，通常应结合轨道仿真、卫星辐射方向图和RNSS接收天线方向图，求实际接收峰值功率的时间历程。[R2，正文第23页/PDF第25页]

所以，初评超限表示在所用假设下不能排除不可接受干扰，需要进一步核实；它不是对所有实际条件下共存不可行的证明。

## 1.2　详评回答“实际会怎样，证据是否充分”

| 问题 | 初评常见处理 | 详评应补充的内容 |
|---|---|---|
| 何时受扰 | 持续最坏照射 | 星历、发射时段、扫描驻留、模式切换与到达时序 |
| 输入多强 | 固定斜距和最大增益 | 双端动态方向增益、传播和极化 |
| 收到什么波形 | 理想矩形谱或带宽重叠 | 实测发射谱、滤波幅相响应和瞬态响应 |
| 哪一级先受限 | 一个输入饱和门限 | LNA、变频、IF、AGC和ADC分级检查 |
| 每脉冲影响多久 | 固定有效脉宽和恢复时间 | 过阈区间、状态恢复、重叠和记忆效应 |
| 多源如何作用 | 单源或独立统计聚合 | 同时可见、相关时序、联合输入和非线性 |
| 导航功能如何变化 | 等效噪声劣化 | 捕获、跟踪、观测量、定位与恢复 |
| 结论多可靠 | 单一确定值 | 不确定度、模型误差、数值收敛和试验 |

详细程度来自建模和证据，不是增加几个计算公式。

## 1.3　详评不是为了把超限“算成合格”

应允许三种结果：实际参数消除了可证明的过度保守性后满足准则；更真实的模型仍超限，需要修改运行条件；或者名义值满足但证据、参数精度或模型可靠性不足，暂不能判定通过。

不能因希望共存就选用较小恢复时间、较低旁瓣或较宽容接收机模型。每次替换初评假设，都应列明新证据及其适用范围。

# 2　适用范围和分析边界

## 2.1　受扰对象在哪里

本方案默认分析天基雷达发射到地面或机载GNSS用户接收机的直达干扰。机载场景需要飞行轨迹、姿态、安装天线和遮挡条件。星上GNSS、同平台自干扰或导航卫星的其他接收链路应单独建模。

RS.2537-0和RS.2165-0均说明，相关方法的应用尚未针对航天器上的RNSS空对空接收机完成评估。因此不能把地面接收机算例直接当作星上兼容性结论。[R1，Scope；R2，Scope]

## 2.2　天基对空雷达不等于对地成像SAR

M.2030面向非RNSS相关无线电源的脉冲干扰，接收机侧分析思想不限于SAR；RS.2537则是EESS有源SAR的具体初评示例。[R2][R3]

可借鉴“发射源—传播路径—接收机响应—性能判定”的框架，但应采用实际雷达的轨道、波束、脉组、跳频、驻留与发射时序。不得直接照搬SAR示例的工作参数或共存结论。采用某种技术分析方法也不自动确定无线电业务归属或授予频率使用权。

## 2.3　直达干扰不是目标回波

主要路径为：雷达发射天线→导航接收天线。有用信号来自导航卫星，而不是该雷达的飞机目标回波。因此，不要将飞机RCS、目标两程回波损耗或雷达自身的脉压增益放入该直达干扰预算。只有另行研究反射散射干扰时，才为相应路径引入散射模型。

雷达接收处理增益不会自动保护另一台GNSS接收机。

# 3　先建立评估约定，再开展计算

本章为工程实施组织建议。依据是RS.2165要求详评考虑真实运行参数、详细接收机特性及相关主管部门参与。[R1，做出建议3、4]

## 3.1　固定研究对象

对每个场景建立唯一编号，例如“雷达模式R03—接收机G02—信号C01—空间场景S05”。记录软件、硬件和参数版本，避免不同章节悄悄替换滤波器、接收机类型、恢复时间或基线。

## 3.2　建立保护准则表

| 字段 | 需要确认的内容 |
|---|---|
| 信号和通道 | 导航系统、信号分量、中心频率和接收通道 |
| 设备用途 | 地面参考、高精度、航空或其他具体应用 |
| 工作状态 | 初次捕获、稳定跟踪、失锁后重捕获 |
| 判据 | 新增劣化限值、连续干扰限制、前端生存与动态范围 |
| 来源 | 标准具体表项、设备规范、试验或共同确认 |
| 时间条件 | 所需观察窗口、平均方式、瞬态与持续要求 |
| 适用范围 | 接收架构、处理方式、环境及未覆盖条件 |

0.1 dB、0.2 dB不是所有GNSS接收机的统一门限。M.2030表2给出的是所列具体类型的代表参数及新增干扰预算，并说明未列出的接收机类型仍需确定参数。[R3，附件1表2]

## 3.3　事先固定判定规则

在获得结果前确定必须覆盖的场景、模型验证范围、不确定度处理、统计分母和试验升级条件。不能在结果超限后临时拉长平均时间或改变判据。

**交付物：评估范围与保护准则确认表。**

# 4　真实输入数据与可信度管理

## 4.1　雷达侧参数

| 类别 | 具体数据 | 用途 |
|---|---|---|
| 轨道与姿态 | 星历、坐标系、时间基准、姿态、指向误差 | 动态几何 |
| 发射功率 | 峰值、模式间变化、脉间噪声、误差 | 峰值及连续干扰 |
| 波形与时序 | 中心频率、脉宽、PRF、脉组、跳频、调制 | 接收波形重建 |
| 实际发射谱 | 主谱、谱肩、杂散、功放谱再生 | 同频及邻频分析 |
| 天线 | 三维方向图、扫描角与频率依赖、极化 | 动态增益及极化耦合 |
| 任务运行 | 工作时段、开关机、驻留、重访、模式切换 | 照射事件 |
| 多系统 | 同时运行的其他卫星、约束和调度 | 聚合评估 |

不得把不同模式中的最大峰值功率、最大脉宽、最高PRF、最大带宽拼成并不存在的“典型系统”。保守包络可以用于筛查，但应明确它不是实际工作模式。

## 4.2　接收机侧参数

| 参数 | 作用与注意事项 |
|---|---|
| 天线方向图、安装与姿态 | 决定到达角依赖的耦合；机体遮挡需实证 |
| RF/IF滤波幅相响应 | 决定各级输入和脉冲振铃，而非只有3 dB带宽 |
| 生存电平 | 判断损坏风险，注明峰值/平均定义 |
| 饱和、阻塞和压缩特性 | 对应具体参考面、频率、波形与状态 |
| AGC、ADC和脉冲消隐 | 决定增益调整、削顶和信号丢失 |
| 恢复时间与恢复轨迹 | 可能随输入强度、波形和前状态变化 |
| 捕获及跟踪参数 | 积分时间、环路更新和工作状态 |
| 噪声与基线干扰 | 构造新增前的统一比较基准 |
| 输出及平滑方式 | 防止低速输出掩盖短时影响 |

M.2496说明接收机输入饱和电平与AGC、ADC、中频实现等有关，不能仅按类型统一假定，应采用恰当的实测或可靠设备数据。[R6]

## 4.3　每项参数注明来源

建议统一为“实测、设备保证、ITU代表值、工程假设”四级，分别记录来源、版本、误差、适用模式和待确认项。假设可以用于敏感性研究，但最终不得改写成已测得性能。

**交付物：参数基线表、参数缺口和不确定度清单。**

# 5　统一功率参考面与前端检查

## 5.1　建立接收链路参考面

建议按实际设备框图至少区分：

| 参考面 | 示例位置 | 对应检查 |
|---|---|---|
| P0 | 无源接收天线输出 | 传播耦合、标准参数参考 |
| P1 | LNA输入 | 生存、压缩及阻塞 |
| P2 | 变频或IF节点 | 级联增益、混频及选择性 |
| P3 | ADC输入 | 满量程、削顶、AGC工作点 |
| P4 | 数字预相关输入 | 消隐、残余干扰和相关处理 |

同一干扰在各级功率不同，门限也不同。若参考门限在LNA输入，就必须与LNA输入的相应功率比较。不能用后级IF滤波的抑制去证明前级LNA不过载。[R6]

## 5.2　三项检查分开做

生存性检查回答器件会否损坏；动态范围检查回答压缩、削顶、阻塞及恢复异常；导航性能检查回答捕获、跟踪和观测量是否满足要求。无损坏不等于合格，保持位置输出也不等于新增干扰预算满足。

初评可以用保守的无滤波峰值预算筛查；详评若计入某段滤波衰减，必须证明该滤波位于所检查器件之前，且适用于相关频率和瞬态条件。[R2，附件1 §4.1；R6]

**交付物：参考面图、增益/损耗链与门限对应表。**

# 6　轨道—姿态—波束动态耦合

本章公式是标准物理关系的工程实现表达，不是ITU新增门限。

## 6.1　统一坐标和时间

设雷达与导航接收机位置为 $\mathbf r_T(t)$、$\mathbf r_R(t)$，则

$$R(t)=\|\mathbf r_R(t)-\mathbf r_T(t)\|$$

$$\mathbf u_T(t)=\frac{\mathbf r_R(t)-\mathbf r_T(t)}{R(t)}.$$

把视线向量转换到发射天线本体坐标，结合波束指向求离轴角；将反方向转换到接收天线坐标求接收增益。注明地心坐标、地固坐标、当地坐标及姿态旋转约定。不能把地心角直接代入本体方向图。

机载接收机应传播自身轨迹和姿态。使用多个卫星时统一发射时刻与接收时刻的基准；对脉冲时序精细计算，应考虑传播时延对到达时刻的影响。

## 6.2　动态峰值链路预算

当各项定义一致时：

$$P_{r,\mathrm{pk}}(t)=P_{t,\mathrm{pk}}(t)+G_t(t)+G_r(t)-L_{\mathrm{prop}}(t)-L_{\mathrm{pol}}(t)-L_{\mathrm{misc}}(t).$$

功率以dBW表示，增益以dBi表示，损耗以dB表示。自由空间项为

$$L_{\mathrm{fs}}(t)=20\log_{10}\!\left(\frac{4\pi R(t)f}{c}\right).$$

已使用方向相关EIRP时，不再重复加发射增益。频率、距离及单位必须一致。附加传播和遮挡项应有来源，不用无依据损耗来抵消超限。

## 6.3　实际发射状态与旁瓣

区分卫星可见但不发射、工作模式变化、主瓣扫过、旁瓣/后瓣耦合、跳频与脉组间歇。主瓣离开并不必然低于接收机门限；应保留门限以上的全部受扰区间。

RS.2537所说的动态分析正是要得到实际功率时间历程，而不是把全天固定成最大增益。[R2，附件2 §3.1]

## 6.4　分层时间分辨率

| 层次 | 主要计算 | 建议实现 |
|---|---|---|
| 轨道层 | 可见性、斜距及慢变几何 | 粗网格筛查和几何包络 |
| 波束层 | 扫描、驻留、模式切换 | 潜在事件局部细化 |
| 脉冲层 | 过阈脉宽、恢复及脉冲重叠 | 事件级或波形级计算 |
| 接收机层 | AGC和环路记忆 | 状态连续的动态响应 |

M.2305采用长期仿真和局部精细仿真组合。其研究中的120天、10秒、50毫秒等是特定系统的设置，不是所有项目的统一规定。[R5]

## 6.5　收敛与漏检检查

工程上将关键窗口的步长减半，比较最大接收功率、最大劣化、超限总时长和单次最长时长。变化超过事先约定数值容差时继续细化。粗网格还应利用几何包络覆盖潜在窄波束事件，避免只细化粗采样已经命中的事件。

**交付物：动态功率/波束状态序列、候选事件表、步长收敛记录。**

# 7　真实频谱与时域响应

## 7.1　频谱积分用于能量耦合

设天线输出参考面的干扰功率谱密度为 $S_{I,0}(f,t)$，到某级之前的线性滤波响应为 $H_j(f)$，则

$$P_{I,j}(t)=\int S_{I,0}(f,t)|H_j(f)|^2\,df.$$

必须注明谱密度是脉内平均、周期平均还是其他定义，频谱与滤波器的增益标定也要一致。周期平均谱积分不能直接代表瞬时峰值。

RS.2311将干扰频谱与接收机及天线滤波响应结合，求进入预相关通带的部分，而不是只比较名义带宽。[R7，§4.4.1]

## 7.2　时域计算用于峰值与过阈区间

在线性条件下：

$$x_j(\tau;t)=h_j(\tau)*x_0(\tau;t).$$

$t$是轨道/波束慢时间，$\tau$是脉冲快时间。由输出包络求峰值、振铃和过阈时间。某级明显非线性后，不能继续用一条全链路线性传递函数，应引入经过验证的非线性或实测响应。

脉冲谱能量、脉内峰值、周期平均和瞬时包络是不同量；各自在正确环节使用，避免重复滤波和重复带宽折减。

## 7.3　验证有效脉宽近似

RS.2537的线性调频算例使用

$$PW_{\mathrm{eff}}=PW\frac{\Delta f}{B_{\mathrm{chirp}}}.$$

此式依赖相应扫频和等效滤波假设。详评先复现原矩形滤波器算例，再替换真实响应，比较峰值、过阈宽度和能量。若差异会改变判定，就保留真实模型。

报告指出，用何种接收滤波衰减水平定义重叠带宽依赖实现；数据缺失时用完全重叠会增加保守性，详评应注意这一点。[R2，附件2 §3.2.1]

**交付物：频谱耦合、滤波后脉冲响应、有效脉宽近似误差。**

# 8　强弱脉冲与接收机恢复模型

## 8.1　允许同一脉冲有不同部分

滤波后的一个脉冲可能中段高于门限、边沿低于门限，也可能形成多个受影响区间。M.2030规定使用实际收到且高于相应门限的脉宽，并计入恢复时间。[R3，式(3a)]

在固定恢复、周期性且不发生复杂相互影响的条件下：

$$PDC_i=(PW_{\mathrm{above},i}+\tau_{\mathrm{rec},i})PRF_i.$$

高于消隐门限、器件压缩门限与ADC等效饱和门限并非总相同，必须按已选接收机模型使用。

## 8.2　工程实现：区间并集

把每次强脉冲导致的信号损失及额外恢复区间记为 $\mathcal S_{i,k}$。在长度为 $W$ 的窗口内，采用

$$PDC_{\mathrm{exact}}=\frac{\mu\left(\bigcup_{i,k}\mathcal S_{i,k}\right)}{W}.$$

这里 $\mu$ 是区间总长度。该工程算法可以处理非固定PRF、脉组、恢复尾迹重叠和同步源，避免重复计算已损失时间。

但多个单独不饱和的信号叠加后可能一起触发过载。因此不能在任何情况下都先对单源分类后简单合并；必要时先形成联合输入，计算接收机联合响应，再生成损失区间。

## 8.3　恢复时间的定义与状态依赖

区分“脉冲结束后的额外恢复时间”和“含脉冲本身的总受影响时间”，不得重复相加。对明显AGC记忆，可用实测确定的状态依赖关系

$$\tau_{\mathrm{rec}}=F(P_{\mathrm{pk}},PW,PRF,\text{工作模式与先前状态}).$$

这是建模形式，不是ITU给定通用函数。恢复终点也应定义，例如相关输出、AGC或观测量回到规定范围，不能凭波形肉眼估计。

## 8.4　弱脉冲贡献

在M.2030的等效模型适用条件下：

$$R_I=\frac{\sum_iP_{i,\mathrm{pk}}dc_i}{N_0B}.$$

使用与标准一致的参考面和定义；弱脉冲并不是“没有饱和就无影响”。M.2220的组合模型有特定的脉冲重叠与消隐处理，不能先把弱脉冲的消隐损失扣除一遍，再原样代入同一解析公式，造成重复修正。[R3，式(2)、(4)；R4]

频谱或处理机理不满足噪声等效近似时，采用相关处理仿真或实测验证，不能一概把残余功率除以带宽。

**交付物：损失区间、恢复模型、弱脉冲参数及适用性说明。**

# 9　多源聚合与动态劣化

## 9.1　先定义基线与新增源组

至少区分已有连续干扰、已有脉冲干扰和新增雷达源组。多颗新增雷达不能每颗分别占用全部新增预算。[R3，表2注3；R1，注1]

## 9.2　统计独立时的聚合

$$PDC_{\mathrm{agg}}=1-\prod_i(1-PDC_i),\qquad R_{I,\mathrm{agg}}=\sum_iR_{I,i}.$$

M.2220明确这一PDC形式依赖统计独立性。同步、相关调度、固定相位或重复脉组场景宜使用联合时序，或扫描相对时序不确定性。[R4]

平均不相关功率在线性域求和；瞬时峰值和非线性响应考虑同时到达及波形。总劣化一般应从聚合参数重新计算，不应任意把单源劣化dB直接相加。

## 9.3　选择与设备一致的接收机分支

定义 $a=I_{0,\mathrm{WB}}/N_0$、$p=PDC$、$r=R_I$。

理想脉冲消隐模型：

$$N_{0,\mathrm{EFF}}=N_0\frac{1+a+r}{1-p}.$$

M.2030饱和模型的等价整理形式：

$$N_{0,\mathrm{EFF}}=N_0\left[\frac{(1+a)(1-p+N_{\mathrm{LIM}}^2p)}{(1-p)^2}+\frac{r}{1-p}\right].$$

应同时核对原式和参数定义，不能因为某个分支给出的数值小就选择它。[R3，附件1 §2.1–2.3]

新增劣化：

$$D(t)=10\log_{10}\frac{N_{0,\mathrm{EFF,new}}(t)}{N_{0,\mathrm{EFF,base}}(t)}.$$

前后保持噪声参考面、设备状态、基线定义和比较窗口一致。

## 9.4　硬限幅特例的关键解释

当 $N_{\mathrm{LIM}}=1$ 且 $R_I\simeq R_Y\simeq0$，在标准规定条件下：

$$D=-20\log_{10}(1-PDC_Y).$$

公共基线项在该增量比值中约掉。因此，实测背景PDC比代表值小，**并不必然降低此特例中新源的增量劣化**。不能把较好背景当成自动消除超限的理由。[R3，式(7a)]

这里的等效噪声含信号损失的折算，不等于物理热噪声真的增加同样比例。

**交付物：基线、新增及聚合参数的时间历程，最坏事件定位。**

# 10　分析窗口和事件统计

## 10.1　三种占空概念不可混用

$d_{\mathrm{tx}}$是雷达发射占空比；$p_{\mathrm{loss}}$是接收机实际损失时间比例；$d_{\mathrm{dwell}}$是波束照射占统计周期的比例。

不能未经验证用 $p_{\mathrm{loss}}d_{\mathrm{dwell}}$ 代替照射期间影响。M.2220的扫描折减有接收机条件，M.2496说明简单动态折减不适用于所有RNSS接收机。[R4，§4.1.4；R6]

## 10.2　窗口选择

解析窗口应包含足够多脉冲，同时几何、波束和接收机状态在窗口内近似平稳。短脉组、快速扫过、AGC持续恢复导致无法同时满足时，升级到事件或状态连续仿真，不任意延长窗口摊薄瞬态。

## 10.3　必须输出的统计量

| 输出 | 用途 |
|---|---|
| 最大劣化与发生条件 | 定位最危险工况 |
| 超限总时间 | 描述累计影响 |
| 单次最长超限时间 | 评估持续受扰 |
| 事件次数和间隔 | 区分偶发与周期性 |
| 同时作用源数量 | 找到聚合主因 |
| 地理、高度、姿态分布 | 找到不利用户条件 |
| 干扰后的恢复时间 | 判断影响是否延续 |

CDF/CCDF或时间百分比必须注明分母：全部任务时间、发射时间、可见时间或指定接收机状态时间。必要时并列给出。

事件稀少或持续很短并不自动允许超过保护准则。详评仍应回到适用判据与共同确认的条件。[R1，做出建议4]

# 11　何时升级到接收机级仿真

| 触发条件 | 为什么需要升级 |
|---|---|
| 波形超出验证范围 | 噪声等效模型可能失真 |
| 门限或恢复未知 | 强弱分类缺乏可靠输入 |
| 跨脉冲AGC记忆 | 固定恢复时间不够 |
| 捕获/重捕获关键 | 稳态跟踪不能代替捕获 |
| 高度非均匀或相干频谱 | 简单功率除带宽不充分 |
| 多源联合过载 | 单源聚合遗漏非线性 |
| 结果接近门限 | 小误差可能改变判定 |

M.2030附件1 §2.3说明了其脉宽、占空比和捕获状态的使用限制，不能认为所有波形均已等同验证。[R3]

## 11.1　接收机级处理链

工程上可建模为：导航信号＋干扰＋噪声→RF/IF滤波→非线性与AGC→ADC→脉冲抑制→相关器→捕获/跟踪→导航输出。

无需每个项目自行开发完整接收机；具有可观测内部状态的真实设备及受控回放也可用于验证。关键是使用真实或已验证的响应，而不是把一个预设损失直接施加在最终输出上。

## 11.2　除了劣化比，还看什么

记录捕获成功率、捕获/重捕获时间、失锁、周跳、数据中断、伪距和载波相位残差、定位误差、恢复轨迹，以及AGC/削顶/消隐状态。上述是建议的验证指标，不在本文中另设统一保护值。

0.2 dB不能直接换算成固定米数。观测量误差到定位误差还依赖处理方式、卫星几何和解算策略。

# 12　射频传导注入试验步骤

本章是依据RS.2311、M.2496组织的工程试验流程，不是对其特定设备结果的普遍推广。[R6][R7]

## 12.1　受控连接与参考面

采用GNSS模拟器与雷达波形发生器，通过合路、衰减和校准链传导到受试机；在屏蔽或其他受控环境实施，避免外辐射。接入位置与仿真参考面一致。绕过了实际有源天线/LNA，就不能声称已验证被绕过部件。

## 12.2　步骤一：建立基线

固定导航信号、信号强度、运行模式及环境，稳定后采集无新增干扰数据。已有背景干扰若被模拟，须在干扰开/关两组中一致保留。捕获、跟踪、重捕获分别定义。

## 12.3　步骤二：输入校准

在接收参考面确认脉内峰值、脉宽、PRF、脉组、门控、中心频率、带宽、带外谱、脉间噪声，以及合路与线缆频响。确认发生器自身不削顶或产生未建模谱再生，不能只记录仪器面板设置。

## 12.4　步骤三：测接收机参数

在设备允许输入范围内做受控扫描，观察饱和转折、AGC变化和恢复。M.2496附件1提供固定占空比、逐步改变功率确定饱和水平的思路。项目还应核实频率偏移、脉宽与重复率是否改变门限和恢复。[R6]

## 12.5　步骤四：动态危险事件回放

从仿真提取代表性 $P_r(t)$、$f_c(t)$、$PW(t)$、$PRF(t)$ 与门控，回放进入照射、最大耦合、退出和退出后恢复。不要只验证恒功率稳态。

## 12.6　步骤五：试验矩阵

| 组别 | 变量 | 验证目的 |
|---|---|---|
| 功率扫描 | 弱、门限附近、强脉冲 | 强弱分支及饱和 |
| 频率扫描 | 同频、边缘、邻频 | 真实选择性与阻塞 |
| 波形扫描 | 脉宽、PRF、脉组 | PDC与恢复 |
| 动态包络 | 扫过、驻留、重访 | 状态记忆及瞬态 |
| 多源 | 重叠、错开、相关时序 | 聚合有效性 |
| 工作状态 | 捕获、跟踪、重捕获 | 状态敏感性 |
| 设备差异 | 样机、温度、软件模式 | 可重复性和外推范围 |

## 12.7　步骤六：配对对照和数据可靠性

使用相邻干扰关—开—关区间识别基线漂移，重复试验给出统计区间。RS.2311中采用2–10个100秒开/关区间是特定试验设置，不是统一测试时长。[R7，§4.3]

防止两种测量偏差：一是1 Hz等低速平滑输出掩盖短事件，应了解估计窗口或采集更快状态；二是失锁通道停止输出后被统计剔除，导致只保留“幸存通道”平均值。失锁、无效和缺测应独立记录。

保持锁定不等于满足0.1或0.2 dB等预算，试验也不能擅自放宽已有保护准则。

**交付物：校准记录、配置、原始日志、统计结果、模型—试验对照。**

# 13　不确定度与敏感性分析

## 13.1　来源

| 来源 | 例子 |
|---|---|
| 发射端 | 功率误差、谱变化、旁瓣与指向误差 |
| 几何和传播 | 星历、轨迹、姿态、遮挡和传播近似 |
| 接收机 | 门限离散、滤波差异、恢复变化、算法模式 |
| 数值和测量 | 时间步长、插值、校准、估计器偏差 |

## 13.2　先判断敏感性再分配精化资源

若整个事件始终远高于饱和门限，微小链路损耗变化可能不如有效脉宽和恢复时间重要；若很多样本在门限附近，功率、滤波器和门限误差会改变强弱分类。分别扫描这些参数，并保留物理关联，不能将本不独立的模式参数随机组合。

## 13.3　名义值不等于稳健通过

工程上可采用事先认可的不利参数包络，或例如

$$D_{\mathrm{nom}}+U_D\leq D_{\mathrm{allow}}$$

的判定组织方式。这里 $U_D$ 的构成及置信含义必须定义；该表达式不是ITU统一强制裕量。明显非线性、相关参数宜直接计算不利组合，不能无依据假定全部独立且高斯。

零次观测到危险事件不是证明不可能发生。必须说明统计周期、覆盖空间、初始条件和模式范围。

# 14　从0.387 dB初评继续到详评的演示

## 14.1　文献算例基线

RS.2537-0的SAR5—SBAS例取 $PW=37.63\,\mu s$、$PRF=1860\,Hz$、重叠比约0.5964、恢复时间 $1\,\mu s$：

$$PDC_Y\approx0.04361,\qquad D=-20\log_{10}(1-PDC_Y)\approx0.387\,dB.$$

超过该接收机算例的0.2 dB，因此报告要求详评。[R2，附件2 §3.1.2，正文第25页/PDF第27页]

## 14.2　不能用长时间平均掩盖瞬态

**演示假设A，不是ITU实际过境数据：**若强照射仅2秒，统计区间100秒，直接平均会得到

$$PDC_{\mathrm{avg}}=0.04361\times2/100=0.0008722$$

并由简式得到约0.0076 dB。但这个数字不能自动代替2秒照射期间的0.387 dB。是否可平均要由适用判据和接收机动态响应决定。

## 14.3　用证据改变实际受影响时间

**演示假设B，不是实测结果：**若真实滤波和接收机验证得到过阈脉宽 $10\,\mu s$、额外恢复 $1\,\mu s$，则

$$PDC_Y=(10+1)\times10^{-6}\times1860=0.02046.$$

若仍符合硬限幅特例条件，

$$D=-20\log_{10}(1-0.02046)\approx0.180\,dB.$$

改变结果的依据必须是经验证的过阈时间与恢复，不是任意平均或主观折减。

## 14.4　聚合和误差仍可能改变判定

若另一个独立新增源 $PDC_2=0.004$，则

$$PDC_{\mathrm{agg}}=1-(1-0.02046)(1-0.004)=0.02437816$$

$$D_{\mathrm{agg}}\approx0.214\,dB.$$

在该特例中重新超过0.2 dB。或者单源名义0.180 dB，但假设的不确定度裕量0.03 dB，则上界约0.210 dB，不能凭名义值判通过。

这些附加数字仅演示工作流程，不构成项目结果。对真实非独立源或其他接收模型应重新计算，不能移用上述简式。

# 15　最终判定和交付物

## 15.1　三层结论

模型结论说明所列条件下的输入、事件、峰值和劣化；验证结论说明哪些模型和参数已测、误差范围及未验证项；兼容性结论说明在明确边界和运行限制下，是否满足适用保护准则，是否仍需协调。

不写笼统的“对卫星导航没有影响”，而写“在所列模式、接收机、地理/高度、基线和多源条件及不确定度处理范围内，满足/不满足对应准则”。未覆盖型号和模式应单列。

RS.2311明确其特定接收机结论不能未经研究推广到其他类型。[R7，§4.2]

## 15.3　可复核的闭环

真实轨道/波束/发射→各参考面动态输入→真实滤波/非线性/恢复→强弱脉冲与联合作用→动态劣化与导航功能→试验和不确定度→判定。

完成详评的标志不是“再算一次劣化比”，而是能解释这个值为什么代表实际设备、实际事件和实际运行条件，并能接受独立复核。
